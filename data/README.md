# LandslideGuard — Data Directory

This directory contains datasets used by the LandslideGuard system.

## Directory Structure

```
data/
├── README.md              ← This file
├── dataset_inventory.csv  ← Machine-readable inventory of all datasets
├── processed/             ← Preprocessed data ready for model training
│   └── dataset.parquet    ← Processed dataset (Parquet format)
└── raw/                   ← Raw downloaded datasets (not committed to Git)
    ├── nasa_glc/          ← NASA Global Landslide Catalog (requires account)
    └── synthetic/         ← Clearly-labelled synthetic development dataset
```

## Data Files

### `processed/dataset.parquet`
- Preprocessed and feature-engineered dataset
- Format: Apache Parquet (efficient columnar storage)
- Generated by: `scripts/prepare_data.py`
- **⚠️ This file contains SYNTHETIC data generated for pipeline testing only**
- Never mix synthetic and authentic data in the same processed file

### `raw/` (not in version control)
- Placeholder directory for downloaded datasets
- See `scripts/download_data.py` for download instructions

## Data Sources

See `dataset_inventory.csv` for the complete inventory.

| Source | Status | Notes |
|--------|--------|-------|
| Synthetic Development Dataset | ✅ Available | Labelled as synthetic; pipeline testing only |
| geoBoundaries India ADM1 / ADM2 | ✅ Cached Locally | `36` States/UTs (`adm1_states.geojson`) + `735` Districts (`adm2_districts.geojson`) + index (`india_districts_index.json`) via `scripts/download_india_boundaries.py` |
| Open-Meteo API | 🔄 Live fetch | No API key required (coordinate-level forecasts/reanalysis) |
| NDMA SACHET CAP Feed | 🔄 Live fetch | Official India CAP alerts (`FetchAllAlertDetails` / RSS XML fallback); strictly separate from ML alerts |
| IMD API (`api.imd.gov.in`) | ⚙️ Configurable | Official IMD endpoints implemented (`IMD_API_KEY`); shows `"Not configured"` until key added to `.env` |
| NASA Global Landslide Catalog | ⛔ Not obtained | Requires NASA Earthdata account |
| SRTM DEM (1-arcsec ~30m) | 🔄 Point SRTM / GeoTIFF | Open-Elevation 4-point stencil fallback + local GeoTIFF reading via Rasterio/PIL |
| Copernicus Sentinel-2 MSI Level-2A | 🔄 Integrated / Scenarios | B04 (Red 665nm) + B08 (NIR 842nm) + SCL cloud mask; 10m Ground Sample Distance; open Copernicus Data Space |

## Data Quality Rules

1. **Never mix** synthetic data with authentic observational data.
2. Always document the `is_synthetic` flag in processed files.
3. Missing rainfall values are **never** silently replaced with zero.
4. Coordinates are validated before processing (latitude: [-90, 90], longitude: [-180, 180]).
5. Timestamps are stored in UTC and converted to local time for display only.

## Adding New Datasets

1. Download raw data to `data/raw/<source_name>/`
2. Add an entry to `dataset_inventory.csv`
3. Create a validation function in `scripts/validate_data.py`
4. Update `scripts/prepare_data.py` to incorporate the new source
5. Re-run the preprocessing pipeline
6. Document in `reports/dataset_report.md`
